# Tracue Landingpage

Landing page for [tracue.com](https://tracue.com) — go-to-market intelligence for teams that build products.

Plain HTML/CSS/JS, no build step. Hosted on GitHub Pages with the custom domain set in `CNAME`.

- Edit content in `index.html`.
- Waitlist form: set `WAITLIST_ENDPOINT` near the bottom of `index.html` to a form backend (e.g. Formspree). While empty, submissions open an email to `hello@tracue.com`.
